# ADE Example

Public static example of the Training ADE v20 vision.

- Live site: <https://agentic-yankiz.github.io/ade-example/>
- Source: `site/`
- Deployment: `.github/workflows/pages.yml`
- Canonical plan: `site/PLAN.md`, rendered in the app at `?board=plan`

The eleven-screen site contains fictional concept data and has no production integrations. It uses pinned browser builds of Marked and Mermaid to render the repository-controlled plan and its diagrams.
